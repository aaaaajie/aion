# 威胁建模维度 · 区块链漏洞挖掘

> 区块链 / 智能合约试题专属深度维度。接题时经 [../threat-dimensions.md](../threat-dimensions.md) 路由加载本文件夹，仅本文件夹 + 公共基础维度进入上下文。

## 适用链路

区块链攻击的一般链路：**合约/链识别 → 代码或交互分析 → 漏洞定位 → 构造交易 → 状态或资金利用 → flag**。建模时沿维度铺开，穷举攻击面后收敛优先级。

## 深度维度自问清单

| 维度 | 自问 | 涉及漏洞类型 |
| --- | --- | --- |
| **合约 / 链识别** | 链（EVM/其他）？合约语言（Solidity/Vyper）？有无源码 / ABI / 地址？ | 识别、源码获取 |
| **重入攻击** | 是否存在跨合约调用后未更新状态？callback 能否重入？ | 单笔重入、跨函数重入、只读重入 |
| **算术安全** | 加减乘除有无溢出/下溢？Solidity <0.8 需显式检查？ | 整数溢出、下溢 |
| **访问控制** | `onlyOwner`/`require` 校验是否缺失？初始化函数/构造函数可被抢注？ | 访问控制缺失、初始化漏洞 |
| **未检查调用** | `call`/`send`/`transfer` 返回值未检查？ | 未检查调用 |
| **委托调用** | `delegatecall`/`call` 到可控目标？storage 布局混淆？ | DELEGATECALL 漏洞、代理冲突 |
| **自毁 / 后门** | 有无 `selfdestruct`/隐藏后门/伪造逻辑？ | 自毁、隐藏后门 |
| **逻辑漏洞** | 竞态 / 状态机错误 / 边界判断缺失 / 权限误配？ | 业务逻辑漏洞 |
| **经济 / DeFi** | 闪电贷 / 预言机操纵 / 价格操纵 / 清算 / 滑点 / 重放？ | 闪电贷攻击、预言机操纵、价格操纵 |
| **签名 / 交易** | 签名可重放/可伪造？私钥泄露？`ecrecover` 校验缺失？ | 签名重放、私钥泄露、重放攻击 |
| **前端 / 钱包交互** | `approve` 钓鱼？授权金额过大？助记词/密钥泄露？ | approve 钓鱼、授权滥用 |
| **跨链 / 桥** | 跨链桥出入金校验？消息伪造？ | 跨链桥漏洞 |

## 区块链攻击链线索

- **flag 位置**：合约状态 / 特定函数返回值 / Challenge 合约的提交条件 / 链下文件。
- **获取路径**：重入/算术 → 掏空合约满足条件；越权 → 调 `owner` 函数；预言机操纵 → 影响价格套利；权限 → 直接调提交 flag 的函数。
- **黑盒无源码时**：先靠 ABI/字节码反编译 + 交互探测梳理函数，再定优先级；`name` 往往提示合约类型（如 `Reentrancy`/`Bank`/`Airdrop`）。

## 建模纪律

穷举后收敛：先铺全维度，再按「难度 × 得分 × 可行性」排优先级；`hint` 是停滞时的方向修正锚点。**你先定方向与优先级，交易构造与链上交互等实操后续环节处理。**
