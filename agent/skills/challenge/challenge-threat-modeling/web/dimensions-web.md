# 威胁建模维度 · Web 漏洞挖掘

> Web 试题专属深度维度。接题时经 [../threat-dimensions.md](../threat-dimensions.md) 路由加载本文件夹，仅本文件夹 + 公共基础维度进入上下文。

## 适用链路

Web 攻击的一般链路：**入口发现 → 参数/功能识别 → 注入与逻辑验证 → 权限提升 → flag 获取**。建模时沿维度铺开，穷举攻击面后收敛优先级。

## 深度维度自问清单

| 维度 | 自问 | 涉及漏洞类型 |
| --- | --- | --- |
| **输入验证 / 注入** | 输入是否进入 SQL / NoSQL / 命令 / 模板 / XML / 路径？转义充分吗、有无二次处理？闭合符偏好？ | SQL注入、NoSQL注入、命令注入、SSTI、XXE、LDAP注入、XPath注入 |
| **认证与会话** | 登录/找回密码有差异响应吗？token/cookie/session 可伪造/篡改/重放？JWT 弱签？ | 弱口令、用户枚举、认证绕过、JWT伪造、会话固定 |
| **访问控制 / 越权** | 接口校验调用者吗？ID 可遍历访问他人资源？垂直/水平越权？校验在哪层？ | IDOR、垂直越权、水平越权、未授权访问 |
| **XSS 与输出** | 用户输入渲染到哪个元素？`innerHTML` 还是 `textContent`？能否打 admin / 拿 cookie / 读 flag？ | 反射XSS、存储XSS、DOM XSS |
| **文件操作** | 上传秒用校验位置与绕过（后缀/双扩展/魔术字节/大小写）？下载/删除路径穿越？上传后被哪个目录解析？ | 文件上传、路径穿越、任意文件读取 |
| **SSRF 与带外** | 是否可让服务端外连（url/redirect/图片/XML 实体）？能读文件/打内网/访问元数据？ | SSRF、开放重定向、SSRF利用链 |
| **反序列化** | 是否有可序列化/反序列化入口？配合什么 gadget（Java/PHP/Py）？ | 反序列化 RCE |
| **业务逻辑** | 金额/数量/折扣/角色/回调 URL 客户端可控？状态机可跳过？并发双花？ | 参数篡改、流程绕过、竞态、支付篡改 |
| **配置与信息泄露** | 备份文件（`*.bak`/`*~`/`.git`）、`robots.txt`、错误泄露、目录列举、默认凭据？ | 敏感信息泄露、配置错误 |
| **CSRF** | 敏感操作是否校验来源？能否诱导受害者执行？ | CSRF |
| **组件与依赖** | 框架/中间件/组件版本已知漏洞？ | 已知CVE、供应链漏洞 |
| **隐藏接口 / JS** | 内联/外部 JS 的 fetch 端点？隐藏路由、管理接口？ | 隐藏接口、未授权接口 |

## Web 攻击链线索

- **flag 位置**：数据库 / 文件 / admin 会话 / 服务端环境变量 / 内网服务。
- **获取路径**：注入读库 → 查 flag 表；上传 shell → 执行命令读 flag；越权 → 读他人 / admin 数据；SSRF → 打内网 / 读元数据。
- **组合利用**：一个入口往往需多步（如先注入拿 admin 会话，再进后台读 flag）。

## 建模纪律

穷举后收敛：先铺全维度，再按「难度 × 得分 × 可行性」排优先级；`name` 是最大线索（如潜在 `Sqli`/`Upload`/`JWT`），`hint` 是停滞时的方向修正锚点。

> **建模 → 执行**：本文件用于威胁建模（铺攻击面、定优先级）。挑战Agent发现能拿 flag 的漏洞后，亲自撰写详细利用任务发布给执行 Agent 去渗透，不依赖固定清单。
