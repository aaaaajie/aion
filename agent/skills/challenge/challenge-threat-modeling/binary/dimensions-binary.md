# 威胁建模维度 · 二进制漏洞

> 二进制逆向 / Pwn 试题专属深度维度。接题时经 [../threat-dimensions.md](../threat-dimensions.md) 路由加载本文件夹，仅本文件夹 + 公共基础维度进入上下文。

## 适用链路

二进制攻击的一般链路：**附件获取 → 静态分析识别漏洞 → 动态调试确认 → 构造利用 → flag 获取**。建模时沿维度铺开，穷举攻击面后收敛优先级。

## 深度维度自问清单

| 维度 | 自问 | 涉及漏洞类型 |
| --- | --- | --- |
| **文件与格式** | 附件是什么格式（ELF/EXE/固件/压缩）？架构（x86/x64/ARM）？有无包壳/混淆？ | 文件识别、脱壳 |
| **保护机制** | NX/ASLR/PIE/RELRO/Stack Canary/Fortify 是否开启？决定利用手法上限。 | 保护识别 |
| **静态逆向** | 反编译伪代码中关键函数在哪？`strcpy`/`gets`/`printf`/`free`/`malloc` 等危险函数？ | 危险函数定位 |
| **输入面** | 程序从哪读输入？stdin/stdout / socket / 文件 / argv / 环境变量？ | 输入点定位 |
| **栈漏洞** | 栈上有无溢出的缓冲区？能否覆盖返回地址 / canary？ | 栈溢出、ret2libc、ROP |
| **堆漏洞** | 堆操作：UAF / double free / heap overflow / tcache 攻击？ | UAF、double free、堆溢出 |
| **格式化字符串** | `printf` 类是否可控格式串？能否任意读/写？ | 格式化字符串 |
| **整数/类型** | 有无整数溢出/下溢、符号/类型混淆、越界索引？ | 整数溢出、类型混淆 |
| **逻辑漏洞** | 有无校验缺失、条件绕过、边界判断错误？ | 逻辑漏洞 |
| **命令注入** | 是否把输入拼进 `system`/`popen`/命令？ | 命令注入 |
| **利用技术** | 基于保护机制选：ROP / ret2libc / ret2plt / shellcode / one_gadget / partial overwrite / SROP / 堆喷？ | 利用链选择 |
| **沙箱/绕过** | 有无 seccomp / 沙箱限制？能否绕过？ | 沙箱逃逸、系统调用绕过 |

## 二进制攻击链线索

- **flag 位置**：内存 / 文件 / 环境变量 / 服务端文件（配合命令注入或读文件原语）。
- **获取路径**：溢出拿到控制流 → ROP 调 `system("/bin/sh")` 或 `open/read/write` 读 flag；格式化字符串任意读拿 flag / 任意写改 GOT；堆利用拿 shell。
- **保护决定手法**：开启 canary 需先泄露；开启 NX 需 ROP 而非 shellcode；PIE 需泄露基址。

## 建模纪律

穷举后收敛：先铺全维度，再按「难度 × 得分 × 可行性」排优先级；`name` 提示类型（如 `shellcode`/`pwn-1`/`ret2libc`），`hint` 是停滞时的方向修正锚点。**你先定方向与优先级，动态调试等实操后续环节处理。**
