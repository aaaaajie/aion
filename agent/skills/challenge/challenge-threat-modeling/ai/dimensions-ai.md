# 威胁建模维度 · AI 漏洞挖掘

> AI / LLM 试题专属深度维度。接题时经 [../threat-dimensions.md](../threat-dimensions.md) 路由加载本文件夹，仅本文件夹 + 公共基础维度进入上下文。

## 适用链路

AI 攻击的一般链路：**接口识别 → 交互面探测 → 提示词/工具/数据攻击 → 越狱/逃逸 → 权限或数据获取 → flag**。建模时沿维度铺开，穷举攻击面后收敛优先级。

## 深度维度自问清单

| 维度 | 自问 | 涉及漏洞类型 |
| --- | --- | --- |
| **交互面** | 模型如何交互？Chatbot / API / 工具调用 / 智能体？输入输出在哪里？ | 接口识别 |
| **提示词注入** | 能否用构造输入覆盖系统指令？直接/间接注入？能否让模型执行非预期动作？ | 直接提示注入、间接提示注入 |
| **越狱 / 逃逸** | 能否绕过安全对齐取到本应拒绝的内容 / 动作？角色扮演、编码、多语言、迭代诱导？ | 越狱、安全对齐绕过 |
| **提示词泄露** | 能否诱使模型吐出系统提示 / 隐藏指令 / 内部上下文？ | 提示词泄露、系统指令提取 |
| **工具 / 权限滥用** | 模型能调用哪些工具（读文件/执行命令/联网/访问数据）？能否诱导其调用危险工具？ | 工具滥用、Agent RCE、工具越权 |
| **数据投毒 / RAG** | 是否基于 RAG / 知识库？能否注入污染检索内容影响回答？ | 数据投毒、RAG 污染、间接注入 |
| **模型提取 / 窃取** | 能否通过交互推断模型参数/结构/训练数据？ | 模型提取、训练数据泄露 |
| **对抗样本** | 输入微小扰动能否使模型输出错误 / 分类逃逸？ | 对抗样本、逃逸攻击 |
| **逻辑 / 幻觉滥用** | 能否利用模型幻觉或逻辑漏洞达成目标（绕过校验、生成 flag 相关逻辑）？ | 逻辑漏洞、幻觉滥用 |
| **隐私 / 敏感泄露** | 模型是否泄露他人会话 / prompt 历史 / 敏感数据？ | 隐私泄露、数据泄露 |
| **资源耗尽 / DoS** | 能否构造超长 / 复杂输入耗尽资源？ | DoS、资源耗尽 |
| **供应链 / 权限边界** | 加载的模型/依赖是否被污染？权限隔离是否被突破？ | 供应链攻击、权限边界绕过 |

## AI 攻击链线索

- **flag 位置**：模型返回内容 / 模型可访问的文件 / 工具调用的后端 / 特权 Agent 的会话。
- **获取路径**：提示注入 → 让模型读文件/执行命令 → 拿 flag；越狱 → 让模型生成本拒内容；RAG 污染 → 诱导模型泄露内部数据；工具滥用 → 调后端接口拿 flag。
- **关键差异**：AI 题目的"漏洞"常是**行为边界**而非传统注入，需反复叠代提示直到模型执行目标动作；**证据要可复现**（同样的提示能稳定触发）。

## 建模纪律

穷举后收敛：先铺全维度，再按「难度 × 得分 × 可行性」排优先级；`name` 是最大线索（如 `prompt-leak`/`jailbreak`/`agent`），`hint` 是停滞时的方向修正锚点。**你先定方向与优先级，多轮叠代提示等实操后续环节处理。**
