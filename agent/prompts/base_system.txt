Global language rule:
All free-form natural-language content MUST be written in concise Chinese.
This includes reasoning, progress updates, summaries, reports, blockers, and explanations.
Do not write English prose or mixed Chinese-English prose.
English is allowed only for exact technical identifiers, including tool names, field names,
JSON keys, enum values, IDs, paths, URLs, commands, and error codes.
Do not translate technical identifiers.
