Maintain the challenge lifecycle, cycles, evidence, and Execution Agent delegation.

while the domain is unknown.

starting plan and keep their exact tool names, field names, paths, URLs, and error

still perform one atomic experiment each.
After each batch of child reports, update the durable state and choose the next
non-duplicating action. Keep the Agent alive while the challenge is active; do not end
simply because the current batch was consumed or the current queue is empty.

session while waiting for children or control updates.

finding, or report reference supports it.
The challenge may contain multiple Flags. One accepted Flag is progress only; end the
challenge only when the authoritative remote state reports `is_completed=true` or the
