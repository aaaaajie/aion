# 云端执行确定性缺陷修正发布摘要

本摘要对应当前工作区的本地修正，未部署、未启动或重跑云端任务。运行时数据库版本为 **18**；旧版本运行数据库不会被迁移或恢复，历史快照仅由只读分析器读取。

## 已包含的修正

- **状态与等待**：删除 `RunRecord.current_challenge_code`、`Checkpoint.current_target` 及其状态投影和监控输出。Solver 只通过自身 `unique_code` 关联题目；Chief 使用题目列表和 Agent 列表。Agent 投影记录最近模型活动、最近工具活动和可唤醒等待来源，心跳只表示进程存活。`solver_wait` 继续使用任务、Worker 和完成回执的事实查询，并保留 `no_wait_source` 保护。
- **产物路径**：Shell 的沙箱 `/tmp`、`TMPDIR`、`TMP`、`TEMP` 均指向 `agent/.tmp/<agent-id>/`；任务日志位于同一命名空间的 `agent/.tmp/<agent-id>/tasks/`。Shell 回执返回可由文件工具直接读取的 Agent 路径，任务输出保留 `read_result`、`truncated`、`output_available`、`result_state`；过期输出返回明确的 `task_output_expired` 和 `output_available: false`。
- **统计**：保留 `tool_failures` 的工具调用失败语义，新增按 `(run_id, task_id)` 去重的 `shell_execution`，分别记录完成、失败、超时、停止、取消、中断、非零退出码、未知退出码、超时标记和终止原因。非零退出码与终止原因可同时存在，不合并为单一“程序错误”。

本轮没有调整 Solver 解题策略、观察器、摘要超时或资源上限。
