## 已实现行为

后台 Shell、网络任务、HTTP 执行及 HTTP 后台分析进入终态后，状态事务提交后通知所属 Agent。HTTP 请求按 interaction 通知，分析按每轮分析的终态变化通知，不逐个响应通知。重复写入终态不会产生新完成通知。

完成送达与输出读取、实验复盘独立。新增内部完成事件投影，按 Agent/Run 过滤，单次按事件顺序展示最多 20 条摘要；成功 assistant_response 原子保存 completion_sequences。失败响应不确认；重新打开状态后沿用事件日志恢复，不依赖进程内通知。HTTP 执行和分析同时完成的同一事件合并送达，不能跨过未展示事件确认。未读输出保留在任务快照，不造成重复模型调用。

入等待在状态写锁内检查未读报告和未送达完成事实，已有事实返回 ready。现有健康检查重新检查持久化事实，覆盖提交后通知丢失；无新事实不调用模型。暂停或终态 Agent 不因通知恢复。网络任务原生状态事件加入执行事实投影和复盘引用范围；后台分析状态进入任务快照。

HTTP 发送及预检共用 tools/http/urls.py 的有效 URL 构造。query 为空保留原 URL；非空只覆盖同名参数，列表发送多值，其他键保留。变量展开后再合并。预检 URL 展示实际合并结果并脱敏；原始持久化请求输入不改写。

删除 Shell 安装命令、容器命令和 socket 字符串的全文拒绝规则，以及专属错误文案。保留 OS 沙箱、受控环境、目录归属、只读挂载和任务回收。安装依赖使用私有工作区或私有虚拟环境，不新增安装器，不改变两种平台的网络策略。
