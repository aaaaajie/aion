# Arjun bundle

This release exposes the non-interactive AION adapter at `bin/arjun`.
The adapter follows the finite differential parameter discovery workflow of
[s0md3v/Arjun](https://github.com/s0md3v/Arjun), pinned to commit
`d1fb995cb1e064d4e171d83f19f6af79b0a3c5ce`.

It supports GET, form POST, JSON and XML requests and returns machine-readable
findings for the Agent tool surface.
